## 写在前面

这份合集把**每个命令的 `-参数` 都拆开讲**。语法：`命令 [选项] [参数]`，`[]` 可选、`<>` 占位、`|` 管道、`.` 当前目录、`~` 家目录、`*` 通配。深入再 `man 命令`。

{% note info %}
示例里的选项可以叠加，比如 `ls -lah` = `-l -a -h` 三个效果合在一起。
{% endnote %}

## 一、文件与目录

### `ls` 列出目录内容
```bash
ls -lah --time-style=long-iso
```
| 参数 | 作用 |
| --- | --- |
| `-l` | 长格式：权限、属主、大小、修改时间 |
| `-a` | 含 `.` 开头的隐藏文件 |
| `-A` | 同 `-a` 但**不**显示 `.` 和 `..` |
| `-h` | 大小用 K/M/G 人类可读 |
| `-t` | 按修改时间排序（新→旧） |
| `-r` | 反转排序方向 |
| `-R` | 递归列出子目录 |
| `-S` | 按文件大小排序 |
| `-d` | 只显示目录本身，不展开内容 |
| `--color=auto` | 按类型彩色输出 |

### `cd` 切换目录
| 参数 | 作用 |
| --- | --- |
| `cd -` | 回到上一次所在目录 |
| `cd ~` / `cd` | 回当前用户家目录 |
| `cd ..` | 上一级 |
| `-L` / `-P` | 逻辑路径 / 解析软链后的物理路径 |

### `pwd` 显示当前路径
| 参数 | 作用 |
| --- | --- |
| `-P` | 解析软链，显示真实物理路径 |
| `-L` | 显示逻辑路径（含软链名） |

### `mkdir` 建目录
| 参数 | 作用 |
| --- | --- |
| `-p` | 递归建多级（`mkdir -p a/b/c`） |
| `-m 755` | 建时直接设权限 |

### `touch` 建空文件 / 改时间戳
| 参数 | 作用 |
| --- | --- |
| `-a` | 只改访问时间 |
| `-m` | 只改修改时间 |
| `-c` | 文件不存在也不新建 |
| `-t [[CC]YY]MMDDhhmm` | 指定时间戳 |
| `-r file` | 参照某文件的时间 |

### `cp` 复制
| 参数 | 作用 |
| --- | --- |
| `-r` / `-R` | 递归复制目录 |
| `-i` | 覆盖前询问 |
| `-f` | 强制覆盖 |
| `-n` | 不覆盖已存在文件 |
| `-u` | 只在源更新时才复制 |
| `-p` | 保留权限、时间、属主 |
| `-a` | 归档模式（= `-rp`，常用于备份） |
| `-v` | 显示正在复制的文件 |
| `-l` / `-s` | 建硬链 / 软链而非复制 |

### `mv` 移动 / 重命名
| 参数 | 作用 |
| --- | --- |
| `-i` | 覆盖前询问 |
| `-f` | 强制 |
| `-n` | 不覆盖 |
| `-u` | 只在源更新时移动 |
| `-b` | 覆盖前先备份 |

### `rm` 删除
| 参数 | 作用 |
| --- | --- |
| `-r` / `-R` | 递归删除目录 |
| `-f` | 强制，不询问、忽略不存在 |
| `-i` | 每个文件前询问 |
| `-v` | 显示删除了什么 |
> ⚠️ `rm -rf` 极易误删，删前先 `ls` 确认路径。

### `ln` 建链接
| 参数 | 作用 |
| --- | --- |
| （默认） | 建**硬**链接 |
| `-s` | 建**软**链接（常用） |
| `-f` | 强制覆盖已存在的链接 |
| `-i` | 覆盖前询问 |
| `-r` | 软链目标用相对路径 |
| `-n` | 把已存在的链接当普通文件，不跟入 |

## 三、文本处理三剑客

### `grep` 搜索文本
```bash
grep -rnE "error|fail" src/ --include="*.ts"
```
| 参数 | 作用 |
| --- | --- |
| `-i` | 忽略大小写 |
| `-v` | 反向：只输出**不**匹配的行 |
| `-n` | 显示匹配行号 |
| `-r` / `-R` | 递归搜索目录 |
| `-l` | 只显示含匹配的文件名 |
| `-c` | 只统计匹配行数 |
| `-o` | 只输出匹配到的那部分 |
| `-w` | 整词匹配（不被子串命中） |
| `-x` | 整行匹配 |
| `-E` | 使用扩展正则（支持 `|` `()` `{}`） |
| `-P` | 使用 Perl 正则（支持 `\d` 等） |
| `-A 3` | 顺带显示匹配行**后** 3 行 |
| `-B 3` | 匹配行**前** 3 行 |
| `-C 3` | 前后各 3 行 |
| `-e PATTERN` | 指定多个模式 |
| `-f file` | 从文件读取模式 |
| `--color=auto` | 高亮匹配 |
| `-q` | 静默，只返回退出码（用于判断） |

### `sed` 流编辑器（默认只打印不改文件）
```bash
sed -i.bak 's/old/new/g' config.yml
```
| 参数 | 作用 |
| --- | --- |
| `-e` | 接一个编辑表达式（可多个） |
| `-f` | 从文件读取 sed 脚本 |
| `-i[后缀]` | **原地**修改；`-i.bak` 先备份 |
| `-n` | 关闭默认打印（配合 `p` 只输出指定行） |
| `-E` / `-r` | 扩展正则 |
> 常用指令：`s/旧/新/g` 替换、`d` 删除、`p` 打印、`a\` 后追加、`i\` 前插入。

### `awk` 按列处理
```bash
awk -F: '$3>1000 {print $1}' /etc/passwd
```
| 参数 | 作用 |
| --- | --- |
| `-F:` | 指定字段分隔符（默认空白） |
| `-v var=val` | 传入变量 |
| `-f file` | 读取 awk 脚本 |
> 内置变量：`$0` 整行、`$1` 第 1 列、`NF` 列数、`NR` 行号、`FS` 分隔符、`OFS` 输出分隔符。

## 四、权限与用户

### `chmod` 改权限
| 参数 | 作用 |
| --- | --- |
| `-R` | 递归 |
| `-v` | 显示每个文件的改动 |
| `-c` | 只在真有改动时报告 |
| `-f` | 出错也不报错 |
> 数字法：`r=4 w=2 x=1`，如 `755`=属主 rwx、组和其他 rx。
> 符号法：`u/g/o/a`（用户/组/其他/全部）`+/-/=`（加/减/设）`r/w/x`，如 `chmod u+x f`、`chmod g-w f`。
> 特殊位：`s`（setuid/setgid）、`t`（粘滞位，如 `/tmp`）。

### `chown` 改属主
| 参数 | 作用 |
| --- | --- |
| `-R` | 递归 |
| `-v` / `-c` | 显示改动 |
| `--from=旧` | 只改属主匹配的 |
> 用法：`chown user:group file`、`chown :group file`（只改组）、`chown user file`（只改用户）。

### `useradd` 建用户
| 参数 | 作用 |
| --- | --- |
| `-m` | 建家目录 |
| `-s /bin/bash` | 指定登录 shell |
| `-G g1,g2` | 附加组 |
| `-g grp` | 主组 |
| `-u 1001` | 指定 uid |
| `-d /path` | 指定家目录 |
| `-r` | 建系统用户 |

### `passwd` 改密码
| 参数 | 作用 |
| --- | --- |
| `-l` | 锁定账户 |
| `-u` | 解锁 |
| `-d` | 清空密码 |
| `-e` | 下次登录强制改密 |
| `-S` | 显示状态 |

### `sudo` / `su`
| 参数 | 作用 |
| --- | --- |
| `sudo -i` | 切到 root 登录 shell |
| `sudo -u user cmd` | 以指定用户执行 |
| `sudo -s` | 以 root 起 shell |
| `sudo -k` | 清除缓存的凭证 |
| `su - user` | 切换并加载该用户完整环境 |

## 五、系统信息与进程

### `ps` 查看进程快照
| 参数 | 作用 |
| --- | --- |
| `aux` | `a` 所有用户 `u` 用户格式 `x` 无终端的也列 |
| `-ef` | 标准格式全量列表 |
| `-eo pid,comm,%cpu` | 只取指定列 |
| `--sort=-%mem` | 按内存倒序 |
| `-u user` | 指定用户 |
| `-p PID` | 指定进程 |
| `-C name` | 按命令名 |

### `top` 实时进程监控
| 参数 | 作用 |
| --- | --- |
| `-b` | 批处理（适合重定向到文件） |
| `-d 2` | 刷新间隔 2 秒 |
| `-n 3` | 只刷新 3 次 |
| `-p PID` | 只看某进程 |
| `-o %CPU` | 按 CPU 排序 |
> 交互：`P` 按 CPU、`M` 按内存、`k` 杀进程、`q` 退出。

### `kill` 发信号
| 参数 | 作用 |
| --- | --- |
| `-l` | 列出所有信号 |
| `-15` / `-TERM` | 终止（默认，优雅） |
| `-9` / `-KILL` | 强制杀死（最后手段） |
| `-1` / `-HUP` | 重载配置（如 nginx） |
| `-2` / `-INT` | 中断（同 Ctrl+C） |
> `kill PID` 给进程发信号；`pkill -f "node server"` 按名字杀；`killall name` 按名杀全部。

### `uname` 系统信息
| 参数 | 作用 |
| --- | --- |
| `-a` | 全部 |
| `-s` | 内核名 |
| `-r` | 内核版本 |
| `-n` | 主机名 |
| `-m` | 硬件架构 |
| `-o` | 操作系统 |

## 八、压缩与归档

### `tar` 打包（最常用）
```bash
tar -czvf app.tar.gz dir/        # 打包并 gzip 压缩
tar -xzvf app.tar.gz -C /tmp     # 解压到 /tmp
tar -tzvf app.tar.gz             # 只列内容不解压
```
| 参数 | 作用 |
| --- | --- |
| `-c` | 创建归档 |
| `-x` | 解压 |
| `-t` | 列出内容 |
| `-v` | 显示过程 |
| `-f` | 指定归档文件（**必须紧跟文件名**） |
| `-z` | 用 gzip 处理（`.tar.gz`） |
| `-j` | 用 bzip2（`.tar.bz2`） |
| `-J` | 用 xz（`.tar.xz`） |
| `-C dir` | 解压到指定目录 |
| `-p` | 保留原权限 |
| `--exclude=pat` | 排除匹配项 |
| `-P` | 允许绝对路径（慎用） |
> ⚠️ 解压前先 `tar -tzvf` 看路径，防 `../` 路径穿越覆盖系统文件。

### `zip` / `unzip`
| 命令 | 参数 | 作用 |
| --- | --- | --- |
| `zip` | `-r` | 递归压缩目录 |
| `zip` | `-q` | 安静 |
| `zip` | `-9` | 最大压缩 |
| `zip` | `-e` | 加密 |
| `unzip` | `-l` | 只列内容 |
| `unzip` | `-d dir` | 解压到指定目录 |
| `unzip` | `-o` | 覆盖不询问 |

### `gzip` 单文件压缩
| 参数 | 作用 |
| --- | --- |
| `-d` | 解压 |
| `-k` | 压缩时保留原文件 |
| `-c` | 输出到标准输出 |
| `-r` | 递归目录 |
| `-9` | 最大压缩 |
| `-l` | 列出压缩信息 |

## 危险操作清单（务必谨慎）

- **`rm -rf /` / `rm -rf ./*`**：`-r` 递归、`-f` 不确认，路径错就全删。先 `ls` 确认，能备份先备份。
- **`chmod -R 777 /`**：整棵树放开，安全灾难。按目录最小授权（文件 644、脚本 755）。
- **`kill -9` 数据库进程**：强制中断可能损坏文件/丢数据，先 `kill -15` 给优雅退出机会。
- **`> file`**：会**直接清空**原文件，想追加用 `>>`；误用 `> config` 会抹掉配置。
- **`find / -name x -delete`**：从 `/` 开始会删系统文件，先不带 `-delete` 跑一遍看结果。
- **`mv a b /` 路径写反**：可能覆盖重要文件，移动前确认目标。
- **`tar` 解未知包**：先 `tar -tzvf` 检查有无 `../../` 路径穿越。
- **`curl -k` / 关闭证书校验**：只在内网调试用，生产别跳过 TLS 校验。

> 黄金法则：**破坏性命令先 dry-run（预览），确认无误再执行；删前能备份就备份。**
